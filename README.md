# EQUINORIX Design

Окрема дизайнерська копія EQUINORIX для погодження візуальних покращень. Основа — тестова версія 20, коміт `20a455908513579a36fbec1a140690552653cb74` (`20a4559`). Цей проєкт розвивається окремо від попередньої копії за ТЗ та основного клієнтського сайту.

Окремий репозиторій: [Svip-web/equinorix-design](https://github.com/Svip-web/equinorix-design).

Опублікована дизайнерська копія: [українська версія](https://equinorix-design.svip201517.chatgpt.site/uk/?v=2). Перегляд приватний і потребує входу через акаунт власника ChatGPT.

## Дизайн і функції

У цій копії дозволено покращувати композицію секцій, типографіку, відступи, картки, кнопки, іконки та адаптивність. Зміст сайту успадковано з базової версії: дизайнерські зміни не додають нових маркетингових текстів і не скорочують описи послуг.

Візуальні покращення цієї версії:

Версія 2 містить погоджені уточнення шапки, синього затемнення, білого тексту, білих фонів і початкової композиції послуг.

- Перший екран із фото Марбельї на висоту вікна, синьою підкладкою, білим текстом і білою головною кнопкою.
- Компонування шапки повернуто до базової версії 20.
- Усі секції після першого екрана мають білі фони.
- Шість послуг у початковій асиметричній композиції на комп’ютері, з круглою CTA та номерами 01–06. Уточнено відступи й адаптивне розташування на менших екранах.
- Панорамне HR-фото без обрізання та дві білі картки по чотири наявні пункти; на телефоні — одна колонка.
- Окремі колонки історії та відео засновниці з переходом в одну колонку на менших екранах. Плеєр має формат 16:9, прямі кути, без рамки й тіні.
- Видимі підписи полів форми використовують уже наявні назви; головні контактні кнопки ведуть безпосередньо до форми.
- Читабельніші контакти й елементи футера, зрозумілий поточний мовний стан та адаптивне меню.

Збережено чотири мовні версії, перемикач мов, закріплену шапку, шість послуг, вісім HR-пунктів, cookies, повернення до форми, відеоблок і WhatsApp. Тексти зберігаються в `content-data.json` та `ui-data.json`; після збірки їх потрібно звіряти з базовою копією.

## Локальний запуск

Потрібен Node.js 20 або новіший. Додаткових npm-залежностей немає.

У PowerShell з каталогу проєкту:

```powershell
npm run build
$env:EQUINORIX_PORT = '4177'
npm start
```

Відкрийте [українську версію](http://127.0.0.1:4177/uk/). Сервер слухає лише `127.0.0.1`; змінна `EQUINORIX_PORT` задає порт цієї окремої копії.

## Перевірки

Залиште сервер запущеним. У другому терміналі з каталогу проєкту:

```powershell
$env:EQUINORIX_PORT = '4177'
npm run check
```

`build` генерує чотири сторінки в `site-copy`. `check` перевіряє синтаксис JavaScript, мовні маршрути, ресурси, кількість послуг, тестовий стан форми й недоступність приватних резервних файлів. Перед публікацією версії 2 пройдено 173 перевірки та 40 браузерних перевірок: чотири мови на ширинах 320, 390, 767, 768, 1023, 1024, 1239, 1240, 1440 і 1920 px. Перевірено відсутність накладань карток і CTA, білі фони, білий текст першого екрана та мобільну шапку й меню. Код і текстовий зміст форми, мов та налаштувань приватності збережено.

## Що ще не підключено

- `preview: true` вимикає реальне надсилання й збереження заявок. Форма показує стан «Повідомлення не надіслано»; корпоративна пошта та перевірка доставки залишаються окремою роботою.
- Справжніх відеозвернень засновниці ще немає. Поки працює спільне тихе 10-секундне демовідео з фото Марбельї. Воно не є зверненням засновниці; мовні файли підключатимуться окремо.
- Адреса, повні реквізити й затверджені тексти privacy, cookies та legal очікуються. Кнопки документів без наповнення неактивні.
- Реальні URL LinkedIn та Instagram не надані. WhatsApp використовує підтверджений номер.
- Робочі переклади UA/RU та змістові розбіжності наданих EN/ES редакцій потребують остаточного погодження.

## Структура проєкту

- `build-local.mjs`, `original-content.mjs` — генерація сторінок.
- `content-data.json`, `ui-data.json` — текстові дані чотирьох мов.
- `site-copy/assets/` — стилі, поведінка інтерфейсу, зображення, шрифти й демовідео.
- `site-copy/assets/config.js` — публічна конфігурація без секретів.
- `server-local.mjs`, `check-local.mjs` — локальний сервер і перевірки.
- `ASSET-SOURCES.txt` — джерела фото та шрифту.

Приватну переписку, доступи, резервні копії хостингу та попередній звіт не включено до цієї копії. Секрети не можна додавати в HTML, JavaScript, конфігурацію або Git.
